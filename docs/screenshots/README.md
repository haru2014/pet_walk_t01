## 🎨 디자인 가이드라인 준수 사항
- **사용자 친화적 용어 통일**: 개발자/엔지니어링 전문 용어(스토리 번호, DB, API 등)를 전면 배제하고 견주 눈높이에 맞춘 따뜻한 직관적 어휘 적용.
- **Local-First & Privacy**: 위치 추적 데이터는 외부 서버에 전송하지 않고 기기에만 안전하게 보관됨을 일관되게 고지.
- **모바일 뷰포트 최적화**: 390 × 844 (iPhone 14/15 표준 비율) 및 Android 최신 스마트폰 풀스크린 기준 고해상도 캡처.
- **이전 스크린샷 보관**: 이전 버전 화면들은 [`docs/screenshots/old/`](old/) 디렉터리에 안전하게 보관되어 있습니다.
