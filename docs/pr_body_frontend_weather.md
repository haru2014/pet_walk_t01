- **작업 목적**:
  1. 클라우드(Render 무료 티어) 슬립 상태에서 발생하는 초기 응답 지연(10~15초)을 견디지 못하고 클라이언트가 3.0초 만에 오프라인 폴백으로 전락하던 타임아웃 문제 해결
  2. 오프라인 폴백 가상 데이터(기온 31℃, 지면열 46℃ 등 시뮬레이션 곡선)가 1시간 동안 브라우저/앱 메모리에 캐싱되어 실제 날씨(우천, 20.8℃)가 복구된 후에도 노출되던 캐시 고정 버그 해결
  3. 홈 화면 당겨서 새로고침(Pull-to-refresh) 추가로 즉각적인 실시간 기상 강제 갱신 지원
  4. 실제 데이터 기반 서비스 원칙에 따른 가상/오프라인 데이터 투명 고지 체계 확립

## 🛠️ 주요 변경 사항 (Key Changes)

### 1. 프론트엔드 타임아웃 및 캐시 정책 현실화 (`weatherApi.ts`, `apiClient.ts`)
- **타임아웃 확장**: `API_TIMEOUT_MS`를 3.0초 $\rightarrow$ **8.0초**로 확대하여 Render 서버의 콜드 스타트 시에도 연결이 중단되지 않고 실시간 데이터를 온전히 수신할 수 있도록 개선
- **폴백 캐시 TTL 분리**:
  - 실서버 정상 응답 (`isLiveServer: true`): **1시간 (`LIVE_CACHE_TTL_MS = 3,600,000ms`)** 유지하여 배터리 및 네트워크 절약
  - 오프라인 폴백 가상 응답 (`isLiveServer: false`): **10초 (`FALLBACK_CACHE_TTL_MS = 10,000ms`)** 만 임시 유지하여, 서버가 깨어나면 10초 후 또는 다음 화면 진입 시 즉시 실시간 데이터로 자동 전환

### 2. 모바일 홈 화면 UX 개선 (`HomeScreen.tsx`)
- `RefreshControl` 컴포넌트 연동: 사용자가 화면을 아래로 당겨 새로고침할 때 `{ forceRefresh: true }`를 전달하여 메모리 캐시를 즉시 무효화하고 최신 기상(기상청/Open-Meteo)을 즉각 재호출
- React Compiler / React 19 cascading renders 린트 에러 방지를 위한 마운트 가드 적용

### 3. 실제 데이터 기반 투명 고지 체계 구축 (`GoldenTimeWidget.tsx`, `CommunityTabScreen.tsx`)
- 네트워크 단절이나 장애로 인해 불가피하게 시뮬레이션 가상 데이터가 노출될 경우, 위젯 상단에 `[가상 데이터 - 오프라인 모드]` 배지 및 안내 문구를 명확히 고지
