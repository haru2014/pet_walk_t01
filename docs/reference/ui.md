# UI Refactoring Specification: 산책 코스 추천 화면 (No-Scroll & Typography +20%)

## 1. 개요 및 목적
* **목적**: 단일 뷰포트(Single Screen, No Scroll)를 유지하면서 텍스트 시인성을 개선하기 위해 전반적인 타이포그래피 크기를 약 **20% 확대**.
* **제약 조건**: 하단 내비게이션 바를 포함하여 화면 세로 스크롤이 발생하지 않아야 함.
* **주요 해결 방식**:
  1. 중복/장문 텍스트 압축 및 레이블 정리
  2. 지도(MapView)의 세로 높이(Height) 축소 (-70~80dp 확보)
  3. 컴포넌트 여백(Padding/Margin) 최적화

---

## 2. 레이아웃 높이(Height) 및 여백 조정 가이드

| 컴포넌트 영역 | 기존 대비 변경 사항 | 높이 스펙 가이드 |
| :--- | :--- | :--- |
| **Top App Bar** | 변경 없음 (타이틀 폰트만 확대) | 고정 높이 유지 (~56dp) |
| **Header Summary** | 안내 텍스트 2줄 -> 1줄 압축 | 세로 패딩 축소, 고정 높이 방지 (`wrap_content`) |
| **Category Chips** | 가로 스크롤(`HorizontalScrollView`) 유지 | chip padding 상하 4dp 축소 |
| **Map View** | 세로 비율 축소 (35% -> 약 25~26%) | 높이 축소: **약 200~210dp**로 제한 |
| **Course Tab Selector** | 탭 버튼 내부 패딩 조절 | 높이 유지하되 폰트 확대 |
| **Course Detail Card** | 중복 텍스트 제거 및 지표 정돈 | 폰트가 커져도 1~2줄 내 유지되도록 유도 |
| **Primary Action Button** | 버튼 텍스트 확대, 상하 패딩 최적화 | 버튼 높이 48~52dp 수준 유지 |

## 3. 텍스트 중복 제거 및 카피라이팅 변경 사항

### 3.1. 상단 안내 영역 (Header Summary)
* **AS-IS:**
  > 지면온도 9.6℃입니다. 🏞️ 대전 유림공원 내부 보행로 · 3안 반시계 방향 1.8km: 실제 보행로 기준 약 28분, 1801m 코스입니다.
* **TO-BE (코스명 제거 및 핵심 지표 압축):**
  > `지면온도 9.6℃ · 실제 보행 기준 약 28분 (1,801m)`

### 3.2. 하단 AI 맞춤 코멘트 박스 (Info Card)
* **AS-IS:**
  > 💡 AI 맞춤 점수 88점: 🏞️ 대전 유림공원 내부 보행로 · 1안 시계 방향 1.9km (실측 최대 경사 4.9%)
* **TO-BE (상단 배지와 겹치는 점수/코스명 제거):**
  > `💡 맞춤 추천 이유: 실측 최대 경사 4.9%로 완만한 코스입니다.`

### 3.3. 코스 상세 지표 박스 (Metrics Box)
* **AS-IS:**
  > 폭신 노면 0% (확인 53%) · 확인된 계단 0회 · 최대 경사 4.9% · 그늘 42%
* **TO-BE (줄바꿈 방지를 위한 간결화):**
  > `그늘 42% · 계단 0회 · 최대경사 4.9% · 폭신노면 0%`

## 4. 타이포그래피 스펙 (+20% 적용)

| UI 컴포넌트 | 기존 추정치 | 적용할 폰트 크기 (+20%) | Font Weight |
| :--- | :--- | :--- | :--- |
| **화면 타이틀** (`추천 산책 코스`) | 18sp | **21~22sp** | Semi-Bold / Bold |
| **상단 헤더 문구** (`고양이5에게 맞는...`) | 16sp | **19sp** | Bold |
| **상단 서브 문구** (`지면온도 9.6℃...`) | 13sp | **15~16sp** | Regular |
| **가로 스크롤 칩** (`고양이5`, `유림공원` 등) | 12sp | **14sp** | Medium |
| **코스 탭 레이블** (`추천 1 · 90점` 등) | 13sp | **15~16sp** | Semi-Bold |
| **하단 코스명** (`대전 유림공원 내부...`) | 17sp | **20~21sp** | Bold |
| **거리/소요시간** (`1.9km · 약 30분`) | 15sp | **18sp** | Semi-Bold |
| **AI 배지** (`AI 맞춤 88점`) | 12sp | **14sp** | Semi-Bold |
| **하단 카드 설명/지표 텍스트** | 12~13sp | **14~15sp** | Regular / Medium |
| **시작 버튼** (`이 코스로 산책 시작하기`) | 16sp | **19sp** | Bold |

## 5. 구현 시 주의사항 (Checklist for Codex)
1. **ConstraintLayout / Flexbox Layout 사용 시**:
   - 지도의 세로 크기 제약조건을 `layout_constraintHeight_percent="0.26"` 또는 명시적 높이 `200dp`로 설정할 것.
   - 텍스트 뷰의 세로 체인(`Vertical Chain`) 여백(`margin_top/bottom`)을 기존 대비 2~4dp씩 압축할 것.
2. **Text Ellipsize 방지**:
   - 텍스트 크기 증가로 인해 잘림 현상이 발생하지 않도록 문구 수정안을 반드시 적용할 것.
3. **Scrollable Container 비활성화**:
   - 루트 또는 메인 컨테이너에 `ScrollView`가 없어도 하단 네비게이션 바 위로 `이 코스로 산책 시작하기` 버튼이 완전히 표시되는지 확인할 것.
