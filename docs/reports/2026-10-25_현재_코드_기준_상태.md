# 편안하개 현재 코드 기준 상태

> 기준일: 2026-10-25  
> 확인 범위: 저장소 코드, 설정 파일, 최근 커밋 및 문서 정적 대조  
> 테스트·빌드·운영 배포는 이번 갱신에서 실행하지 않았습니다.

## 요약

편안하개는 Expo SDK 57 기반 React Native 앱과 FastAPI 백엔드로 구성된 반려견 산책 서비스입니다. 앱은 반려견·산책 설정, 경로 추천 및 재생성, 지도 기반 산책 진행, 음성 안내, 기록·커뮤니티 기능을 제공하는 구조입니다. 백엔드는 산책 경로 계획과 재탐색, 날씨·주차장 조회, 위험 제보·전방 안전 확인, 커뮤니티 공유 API를 제공합니다.

## 현재 코드에서 확인한 기능

| 영역 | 확인된 구현 |
|---|---|
| 모바일 앱 | Expo SDK 57, React Native 0.86, TypeScript. 화면 코드는 `frontend/src/`와 `frontend/App.tsx`에 있습니다. |
| 산책 계획 | `POST /api/v1/walk/plan`에서 시간·속도를 바탕으로 목표 거리를 계산해 경로 계획 에이전트에 전달합니다. 공원 모드에서는 공원 보행망 후보를 만들고 계단·경사·노면·그늘 등 프로필을 점수화합니다. |
| 대안 코스 재생성 | `regenerate_nonce`를 통해 다시 추천 회차를 전달합니다. 공원 코스는 1번을 유지하고 2·3번 후보를 이전 대안과의 경로 겹침이 50% 미만인 경로부터 고릅니다. 부족하면 기존 경로의 반대 방향 및 다른 후보로 보충합니다. 모든 장소에서 새 경로 또는 일정한 거리 차이를 보장하는 것은 아닙니다. |
| 순환 코스 표시·안내 | 공원 코스 경로에서 순환 진입점, 순환 길이, 반복 횟수를 추정해 추천 카드와 산책 안내에 표시하는 코드가 있습니다. |
| 안전·외부 정보 | 경로 우회, 전방 안전, 현장 위험 제보, 기상 열 위험도, 공영주차장 조회 API가 있습니다. |
| 공유·저장 | 커뮤니티 피드·공유, 산책 기록 공개/해제, Supabase 연동 코드가 있습니다. `/api/v1/community/share`는 본문 `user_id`를 저장하지만 토큰 검증은 하지 않습니다. `/api/v1/walks/{walk_id}/share`와 `/unshare`는 Bearer 토큰과 소유권을 확인합니다. 계정·서비스 구성 및 실제 운영 연동은 배포 환경에서 별도 확인해야 합니다. |

## 주요 서버 엔드포인트

| 메서드 | 경로 | 역할 |
|---|---|---|
| `GET` | `/health`, `/health/walk-share` | 상태·공유 설정 확인 |
| `POST` | `/api/v1/voice/transcribe`, `/api/v1/voice/tts`, `/api/v1/voice/intent` | 음성 전사·음성 합성·음성 의도 분석 |
| `POST` | `/api/v1/walk/plan`, `/api/v1/walk/reroute`, `/api/v1/walk/forward-safety` | 경로 생성·우회·전방 안전 확인 |
| `POST` | `/api/v1/surface/inspect` | 현장 사진 판독 |
| `POST`, `GET` | `/api/v1/hazards` | 위험 제보 등록·조회 |
| `POST` | `/api/v1/community/share` | 코스 공유 등록 |
| `GET` | `/api/v1/community/feed` | 공유 코스 피드 조회 |
| `POST` | `/api/v1/walks/{walk_id}/share`, `/api/v1/walks/{walk_id}/unshare` | 산책 기록 공개·해제 |
| `GET` | `/api/v1/weather/heat-risk`, `/api/v1/parking/nearby` | 날씨·주차장 조회 |

세부 요청·응답 명세는 [API 정의 및 구현 현황 목록](../07_편안하개_API_list.md)을 참조하세요.

## 사용자 스토리별 구현 현황

판정 기준은 [사용자 스토리 및 완료 정의](../03_편안하개_Agile_User_Stories.md)의 스토리·인수 조건입니다. 아래는 2026-10-25 코드 정적 확인 결과이며, **스토리 문서의 체크 표시를 그대로 옮긴 완료 판정이 아닙니다.** 이번 갱신에서는 테스트, 실기기, 외부 API, CBT를 실행하지 않았으므로 코드가 있다고 해서 모든 인수 조건이 검증됐다는 뜻은 아닙니다.

- **코드 확인**: 앱/백엔드 제품 코드에서 핵심 흐름을 찾음. 성능·실기기·전체 인수 조건은 별도 검증 필요.
- **일부 구현**: 관련 코드 일부는 있으나 명세의 일부 조건·통합·운영 검증이 확인되지 않거나 동작 범위가 다름.
- **제품 코드 미확인**: 앱/백엔드 제품 경로에서 기능 통합을 찾지 못함. 테스트 모듈의 예시 함수만으로 구현 완료로 보지 않음.
