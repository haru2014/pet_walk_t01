## 4. 앱 쪽에서 확인된 사실 (4번 담당 참고)

- 현재 위치 모드에서 3개 코스가 같은 8각형: 서버 응답이 아니라 앱의 대체 경로 `createCurrentLocationFallbackPlan` (`frontend/src/services/api.ts`). 서버가 응답하면 3개 코스는 서로 다른 길입니다(겹침 0.00~0.20).
- `EXPO_PUBLIC_API_URL` 끝에 `/` 가 있으면 `apiClient.ts` 가 `//api/...` 로 이어 붙이고, 운영 서버는 이 주소에 **404** 를 줍니다 (`/health`, 날씨, `walk/plan` 모두 직접 확인 ✅). 주소 끝 `/` 를 지우는 한 줄 보강을 권합니다.
- `frontend/.env.example` 기본값이 `http://127.0.0.1:8000` 이라, 폰에서 이 값을 쓰면 서버에 요청이 가지 않습니다.
