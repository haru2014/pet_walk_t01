## 📋 2. 시나리오별 E2E 검증 기준 (Acceptance Criteria)

1. **CBT-01 (유림공원 · 토리)**:
   - 요청: `origin_mode="park"`, `pilot_park_id="yurim"`, `target_duration_minutes=30`, `joint_care_level=2`
   - 인수 기준: `stairsCount == "확인된 계단 0회"`, `maxSlopePercent <= 5.0`, 응답 레이턴시 ≤ 1.5s
2. **CBT-02 (송강근린공원 · 맥스)**:
   - 요청: `origin_mode="park"`, `pilot_park_id="songgang"`, `target_duration_minutes=40`, `speed_kmh=4.2`
   - 인수 기준: 코스 거리 2,000m 이상, 순환 폐곡선 오차 20m 이내 수렴
3. **CBT-03 (도안호수공원 · 초코)**:
   - 요청: `origin_mode="parking_pnr"`, `parking_lot_id="opr_doan_a"`, `target_duration_minutes=30`
   - 인수 기준: `parking_lot.parking_id == "opr_doan_a"`, 코스 시작/종료점이 주차장 출입구 좌표에 스냅
4. **CBT-04 (세종호수공원 · 보리)**:
   - 요청: `origin_mode="parking_pnr"`, `parking_lot_id="pkg_sejong_02"`, `target_duration_minutes=30`
   - 인수 기준: `entry_approach_m > 0`, 진입로 왕복 안내 문구 포함, 거리 점수 미감점
5. **CBT-05 (도안호수공원 · 콩이)**:
   - 요청: `origin_mode="park"`, `pilot_park_id="doan"`, `target_duration_minutes=20`, `joint_care_level=3`
   - 인수 기준: 완만한 보행로 1위 추천, 질병 용어(Zero Medical Slang) 배제 브리핑

## 📱 3. 현장 실기기 검증 절차 (김승현·김정님 협업)

1. **출발 전**:
   - 앱 홈 화면 골든타임 위젯 및 주차장 선택 확인
   - 코스 선택 시 `PlanSourceBadge`(실측 안심) 표시 확인
2. **산책 중 (Eyes-Free)**:
   - 스마트폰 화면 끄고 주머니에 수납 (다크 포켓 모드 진입)
   - 분기점 30m 전 TTS 턴바이턴 음성 안내 청취
   - 스마트 돌발 짖음 감지 시 3초 자동 음소거 정상 동작 확인
3. **산책 후**:
   - 완주 인포그래픽 리포트 생성 및 3초 원터치 체감 피드백 기록
   - SUS 10문항 설문 및 정량 평가표 작성
