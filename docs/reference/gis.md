# 산책 경로 생성을 위한 공공 GIS 데이터 분석 및 구축 가이드

공공 GIS 데이터를 활용하여 산책로 및 보행 경로(라우팅 엔진 등)를 구축할 때 필요한 **계단, 경사로/경사도, 노면 형태** 데이터의 가용성, 출처 및 실무 처리 방안을 정리한 문서입니다.

---

| 항목 | 포함 여부 | 주요 소스 및 데이터셋 | 속성 및 특징 |
| :--- | :---: | :--- | :--- |
| **계단** | **포함됨** | • 국토교통부/한국교통안전공단 보행자 네트워크<br>• 서울시 등 지자체 도보 네트워크<br>• 국토지리정보원 수치지도(1:1,000 / 1:5,000) | • 링크 속성(`LINK_TYPE` 등)에 '계단', '육교', '지하보도', '일반보도'로 구분 제공<br>• 수치지도 내 계단 레이어(F001 등)로 폴리곤 또는 라인 형상 제공 |

## 2. 주요 데이터 수집 출처

1. **국가공간정보포털 / 국토정보플랫폼 (국토지리정보원)**
   * **보행자용 네트워크 데이터**: 횡단보도, 계단, 육교, 지하도 등이 링크/노드 단위로 구분되어 있어 경로 탐색 시 계단 회피 및 가중치 적용 가능.
   * **수치표고모델 (DEM, 5m/10m 해상도)**: 보행 링크 노드의 3차원 고도값 매핑용 표준 데이터.

2. **공공데이터포털 (data.go.kr)**
   * 지자체별 보행 네트워크 데이터 (예: 서울시 보행 네트워크 공간정보).
   * 교통약자(장애인·노약자) 안전 보행 경로 및 이동편의시설 데이터(턱, 단차, 경사로 위치).

3. **산림빅데이터거래소 및 산림청 공간정보**
   * 도심 근교 둘레길, 숲길, 등산로 코스 데이터.
   * 노면 포장 상태(비포장, 토사, 야자매트, 목재 데크 등) 및 난이도 등급 정보 포함.

## 3. 실무 알고리즘 구현 파이프라인

```
[공공 보행자 네트워크 (링크/노드)] ───┐
                                      ├──> [GIS 공간 결합 및 속성 가공] ───> [경로 탐색 가중치 매트릭스]
[국토지리정보원 DEM (수치표고모델)] ──┘             │
                                                    ▼
[산림청 / OSM 노면 속성 보완] ──────────────────────┘
```

### 단계별 가공 방식

1. **계단 처리 (Stairs)**
   * 보행 링크의 속성 필드에서 `계단` 식별.
   * **구현:** 유모차·휠체어 경로 탐색 시 해당 링크 `Cost = Infinity` (배제), 일반 산책로는 사용자 선호도(운동 목적 vs 편안한 산책)에 따라 가중치 차등 부여.

2. **경사도 산출 (Slope Calculation)**
   * 각 보행 링크의 시점(Start Node)과 종점(End Node) 좌표 $(X, Y)$에 DEM 래스터를 샘플링하여 고도 $Z_1, Z_2$를 추출.
   * 링크의 수평 거리($L$)를 기준으로 경사도 계산:
     $$\text{경사도}(\%) = \left( \frac{|Z_2 - Z_1|}{L} \right) \times 100$$
   * 완만한 산책로($< 5\%$), 다소 가파른 길($5\% \sim 10\%$), 고난도 구간($> 10\%$)으로 구간화하여 경로 탐색 비용(Cost) 함수에 반영.

3. **노면 데이터 보완 (Surface Filling)**
   * 도심 공공 GIS의 노면 결측치는 **OpenStreetMap(OSM)**의 `surface` 태그(`paved`, `unpaved`, `asphalt`, `concrete`, `wood`, `dirt` 등)를 공간 조인(Spatial Join)하여 보충.
   * 숲길/공원 구간은 산림청 등산로 노면 코드를 우선 매핑.
