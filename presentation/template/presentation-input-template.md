# 발표 제작 입력 템플릿

발표를 요청할 때 필요한 정보를 정리하는 재사용 양식입니다. 이 파일을 복사해 `presentation/input/`에 발표별 브리프를 저장하거나, 같은 항목을 요청 메시지에 적어 주세요. 이미 대화에서 제공한 정보는 반복 입력하지 않아도 됩니다.

빈 항목은 미정으로 취급합니다. 자료에 없는 사실이나 성과를 임의로 채우지 않습니다.

## 발표 브리프

- **발표 주제:**
- **발표 목적:** 청중이 발표 후 이해하거나 결정해야 할 내용
- **청중:** 역할, 사전 지식, 관심사
- **내용 범위:** 포함할 내용
- **제외할 내용:** 다루지 않을 내용
- **발표 시간:**
- **질의응답 시간:**
- **분량:** 슬라이드 수 또는 희망 분량
- **언어 및 어조:**
- **출력 형식 및 저장 위치:** 기본 형식은 PPTX이며, 다른 형식이나 위치가 있으면 적어 주세요.
- **디자인 기준:** 디자인 시스템, 템플릿, 브랜드 자료 경로 또는 URL
- **필요한 산출물:** 발표자 노트, 부록, PDF 등
- **시연/영상/음성 필요 여부:**
- **검토 시 제약:** 공개 금지 정보, 반드시 포함할 문구, 사용 금지 자료 등
