# Sorbet 테마 시제품 검토 기록

## 결과물

- PowerPoint: `../output/sorbet-spike.pptx`
- 작업본과 렌더링: `../.build/`
- 슬라이드 수: 3
- 화면 비율: 4:3 (960×720)
- 테마: `../design-system.md`의 Sorbet 색상과 둥근 패널

## 확인 내용

- 세 장을 각각 렌더링해 화면 배치, 넘침, 겹침을 육안으로 확인했습니다.
- PPTX 내부 글꼴 메타데이터에 제목용 Baloo 2와 본문용 Quicksand가 기록되어 있습니다.
- 생성 PC의 Windows 글꼴 폴더에서는 Baloo 2, Quicksand, Pretendard 설치를 확인하지 못했습니다. 따라서 현재 렌더 결과의 글꼴 모양은 지정 글꼴의 실제 설치 환경 렌더링으로 검증되지 않았습니다.
- 최종 파일은 작업 후보와 SHA-256 값이 동일함을 확인했습니다. 검증 도구가 마지막 파일 게시 과정에서 Windows 하드링크 오류를 냈으므로 검증 영수증은 생성되지 않았습니다. 결과물은 후보 PPTX의 바이트 동일 복사본입니다.
- 이 시제품은 레이아웃·도구 확인용입니다. 편안하개 프로젝트의 실제 내용과 성과를 담은 발표 자료가 아닙니다.
