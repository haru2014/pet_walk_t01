## 👥 3. 주차별 팀원별 전담 해야 할 일 (Weekly R&R)

### 1주차 (~ 10월 11일): 요구사항 정의, 아키텍처 및 TDD 기반 환경 구축 (완료)
* **조현정 (팀장 / PM & AI Agent Lead)**
  - 전체 프로젝트 기획 리딩 및 5인 팀원 실명 R&R 매핑 확정.
  - 15개 핵심 애자일 사용자 스토리(US-A1 ~ US-H1) 및 DoD 수립.
  - AI 문제 정의서(`docs/04`) 및 핵심 오케스트레이션 아키텍처 수립.
* **전황진 (데이터 / AI & Spatial Data Engineer)**
  - 국토교통부/지자체 무장애길 및 OpenStreetMap(OSM) 데이터 수집.
  - 수치표고모델(DEM) 래스터 및 기상청 단기예보 API 규격 검토.
* **노희선 (서버 / Backend & Spatial Routing Lead)**
  - FastAPI 프로젝트 환경 셋업 및 REST API v1 DTO 계약 규격 정의.

* **김승현 (앱 / Frontend & Mobile App Lead)**
  - React Native (Expo SDK 51+) 프로젝트 아키텍처 초기화.
  - Android Foreground Service 및 백그라운드 GPS 권한 체계 검토.
* **김정님 (UI / UI/UX Designer & Product Experience Lead)**
  - 편안하개 디자인 시스템(컬러 토큰, 타이포그래피, 고대비 규격) 정의.
  - 주요 5개 화면 와이어프레임 설계 및 웰니스 카피라이팅 원칙 수립.

### 2주차 (10월 12일 ~ 10월 18일): 코어 기능 개발 및 1차 모듈 구현 (Sprint 1)
* **조현정 (팀장)**
  - LangGraph ReAct Walk Planning Agent 코어 노드(`parse_intent`, `calibrate_constraints`) 구현.
  - 자연어 의도 파싱(`WalkIntent`) Pydantic V2 Strict Schema 검증 및 불명확 질의 Fallback 구현.
  - 체급별(소형/중형/대형/노령견) 표준 보행 속도 상수 및 거리 환산 모델 연동.
* **전황진 (데이터)**
  - OSM 보행 네트워크 계단(`highway=steps`) 및 단차 링크 필터링 파이프라인 구축.
  - DEM 고도 래스터 기반 링크별 종단 경사각(15도 미만) 산출 로직 구현.
* **노희선 (서버)**
  - FastAPI Stateless 코어 라우팅 엔드포인트(`POST /api/v1/walk/plan`) 구현.
  - Routing API Adapter 연동을 통한 기본 순환 루프 후보(2~3개) 생성 API 개발.
* **김승현 (앱)**
  - React Native Navigation 구조 구축 (온보딩 $\to$ 플래너 $\to$ 지도 프리뷰).
  - Local-First 영속 스토리지(`AsyncStorage`) 모듈 개발 (반려견 프로필 CRUD).
  - `react-native-maps` 기본 지도 컴포넌트 렌더링.
* **김정님 (UI)**
  - 온보딩 반려견 프로필 입력 UI 및 산책 플래너 슬라이더/칩 인터랙션 UI 개발.
  - 시인성 중심 카드 컴포넌트 디자인 구현.

### 3주차 (10월 19일 ~ 10월 25일): 핵심 차별화 기능 결합 및 내비게이션 엔진 (Sprint 2)
* **조현정 (팀장)**
  - Candidate Route Scorer 100점 만점 채점 알고리즘 결합 (계단 30, 경사 30, 열안전 20, 거리 20).
  - 클라이언트 최근 피드백(`too_steep`) 연동 무상태(Stateless) 허용 경사도 1~2%p 하향 보정 엔진 구현.
* **전황진 (데이터)**
  - 기상청 단기예보(기온, 일사량) 연동 지면온도 추정 모델(35℃ 초과 고온 노면 회피) 파이프라인 개발.
  - 전국 공영주차장 API 클라이언트 및 거점 연계 P&R 데이터 정제.
* **노희선 (서버)**
  - 무장애길 하드 제약(계단 배제) 및 지면온도 페널티 가중치 라우팅 비용 함수 구현.
  - Supabase Auth 기반 간편 이메일 가입/로그인 및 공개 코스 피드 API 개발.
* **김승현 (앱)**
  - Android Foreground Service 기반 화면 꺼짐 무중단 GPS 로깅 엔진 개발.
  - `expo-speech` 회전 30m 전 사전 음성 안내 브리핑 엔진 개발.
  - 지도 위 구간별 색상 분기 Polyline(🌿 완만, 🏢 일반, ⚠️ 주의) 렌더링.
* **김정님 (UI)**
  - 주머니 속 배터리 소모를 극소화하는 **'초절전 다크 포켓 모드'** UI 개발.
  - 산책 완주 인포그래픽 리포트 화면 및 3초 원터치 체감 피드백 UI 완성.

### 5주차 (10월 30일 ~ 11월 4일): 집중 앱 테스트 & 최종 제출

#### 🧪 [10월 30일 (금) ~ 11월 3일 (화)] 집중 앱 테스트 (Field CBT & QA)
* **공통 참여 과업**:
  - 개발팀 5인 및 실제 반려견 견주 5인 이상 대상 **실제 야외 필드 산책 현장 테스트 실행**.
  - 스마트폰을 주머니에 넣고 화면을 끈 상태에서의 **시선 해방 핸즈프리 음성 안내** 집중 검증.
  - 계단 배제 여부, 경사도 완만함 체감, 고온 노면 회피 정확도 평가.
* **팀원별 테스트 전담 역할**:
  * **조현정 (팀장)**: CBT 피드백 정량 수집 분석, Scorer 가중치 미세 튜닝, 최종 발표 자료(PPT) 및 데모 영상 기획 총괄.
  * **전황진 (데이터)**: 현장 산책로 경사도 체감과 DEM 데이터 간 정합도 검증 및 공간 데이터 보정.
  * **노희선 (서버)**: 테스트 기간 중 서버 API 트래픽 및 예외 로그 실시간 모니터링, 엣지케이스 백엔드 패치.
  * **김승현 (앱)**: 필드 테스트 중 발견된 GPS 튀김 및 음성 타이밍 이슈에 대해 **`eas update` 무선 OTA로 실시간 핫픽스 배포**.
  * **김정님 (UI)**: 사용성 평가(Usability Testing) 설문 데이터 분석, UI 버그 픽스 검증 및 완주 리포트 가독성 보완.

#### 🏁 [11월 4일 (수)] 프로젝트 최종 제출 마감 (Final Submission)
* **조현정 (팀장)**: 최종 발표 PPT 완성, 프로젝트 총괄 산출물 최종 승인 및 제출.
* **전황진 (데이터)**: 데이터 파이프라인 및 공간 분석 결과 보고서 정리.
* **노희선 (서버)**: 백엔드 API 명세서 및 서버 실행 가이드 최종본 정리.
* **김승현 (앱)**: 모바일 앱 릴리즈 태깅 및 배포 결과 보고서 취합.
* **김정님 (UI)**: 최종 UI 디자인 산출물, CBT 사용성 평가 보고서 및 데모 시연 영상 최종 렌더링.
