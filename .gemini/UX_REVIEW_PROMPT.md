# PawTrail UX Review & Improvement Prompt

## 🎯 목적
Gemini Code Assist가 **PawTrail (반려견 맞춤형 안심 노면 산책 플랫폼)**의 프론트엔드 UI를 분석하고, 실사용자(야외 견주 5인 CBT) 관점에서 UX 결함과 사용성 문제를 우선순위화하여 최소 변경으로 개선하도록 지원하는 작업용 프롬프트입니다.

---

## 🧭 기본 실행 원칙
1. `.gemini/UX_COMPACT_RULES.md`에 정의된 10대 UX 원칙(야외 시인성, 한 손 조작, 노면 색상 규격, 외부 지도 딥링크 등)을 기본 정책으로 적용합니다.
2. 기획서(`docs/01_PawTrail_Project_Proposal.md`) 및 사용자 스토리(`docs/03_PawTrail_Agile_User_Stories.md`)의 요구사항을 기준점으로 삼습니다.
3. 요청되지 않은 전면적인 리디자인을 지양하고, **문제를 정확히 진단한 후 가장 영향도가 높은 부분부터 최소 단위로 개선**합니다.

## 🔍 Phase 1 — Target & Context Analysis (대상 분석)

리뷰 대상 화면/컴포넌트의 컨텍스트를 먼저 파악합니다.

- **대상 화면**:
  - [ ] 반려견 프로필 등록/수정 화면 (견종, 나이, 관절 질환 단계)
  - [ ] 산책로 플래너 (출발지, 시간, 선호 노면 선택 칩: 흙/잔디/우레탄/보도블록)
  - [ ] 지도 경로 프리뷰 (노면별 색상 Polyline, 총 거리/시간/노면비율 요약)
  - [ ] 외부 지도 길찾기 연동 (네이버/카카오 지도 딥링크)
  - [ ] 현장 노면 카메라 진단 (사진 업로드, 비전 위험도 점수/코멘트 모달)
  - [ ] 산책 완료 체크인 & 피드백 (노면 만족도 별점, 태그, 후기 작성)
  - [ ] 커뮤니티 피드 & 코스 공유
- **주요 사용자 페르소나**:
  - 슬개골 질환 소형견 견주 / 원정 산책 대형견 견주 / 한낮 지면열을 피하려는 노령견 견주
- **사용 환경**:
  - 야외 직사광선 환경, 한 손에는 리드줄을 쥐고 다른 손으로 스마트폰을 조작하는 상황

## 📋 Phase 2 — PawTrail 특화 UX Audit (10대 점검 영역)

1. **Outdoor Readability & Contrast**: 햇빛 아래에서 글자와 지도 선(Polyline)이 잘 보이는가? (대비 4.5:1 이상)
2. **One-Handed Usability (Thumb Zone)**: 핵심 액션 버튼이 하단 40% 영역에 배치되어 있는가?
3. **Touch Target Size**: 필터 칩과 버튼의 터치 영역이 최소 48×48px을 만족하는가?
4. **Surface Color Consistency**:
   - 잔디(초록), 흙(갈색), 우레탄(주황), 보도블록(파랑), 위험/아스팔트(회색/빨강) 규격을 준수하고 텍스트 라벨을 병기했는가?
5. **Transparency of AI Reason**: AI가 왜 이 코스를 추천했는지(노면 구성 비율 등) 사용자가 즉시 이해할 수 있는가?
6. **Navigation & External Fallback**: 모바일 웹 백그라운드 GPS 차단에 대비해 외부 지도 앱 딥링크 버튼이 눈에 띄게 제공되는가?
7. **Vision Feedback Speed**: 사진 촬영 후 로딩 및 판독 결과가 3초 이내에 매끄럽게 전달되는가?
8. **Loading / Empty / Error States**:
   - 경로 탐색 중 로딩 스켈레톤 제공 여부
   - 산책 기록이 없을 때의 Empty State 유도
   - 경로 탐색 실패 또는 비전 인식 실패 시 명확한 대안 제시 여부
9. **Safe Area & Mobile Viewport**: 노치, 하단 홈 인디케이터 영역 침범 방지 여부
10. **Regression Risk**: 기존 비즈니스 로직이나 Pydantic/GeoJSON API 인터페이스를 훼손하지 않는가?

## ⚖️ Phase 3 — Prioritization (우선순위 분류)

- **[P0 - 치명적 결함]**:
  야외에서 터치가 안 되거나 핵심 버튼이 가려져 길찾기/산책 생성이 불가능한 경우.
- **[P1 - 주요 사용성 저해]**:
  노면 색상 구분이 어렵거나, 외부 지도 딥링크 실패, 에이전트 추천 이유가 누락되어 신뢰를 떨어뜨리는 경우.
- **[P2 - 일반 개선]**:
  로딩 스피너 애니메이션 미흡, 여백 불일치, 텍스트 가독성 소폭 개선 등.
- **[P3 - 마이너 폴리시]**:
  마이크로 인터랙션 및 추가 시각 효과.
