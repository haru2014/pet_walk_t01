## 🧭 3. 문서 갱신 및 형상관리 원칙

1. **최신성 보존과 이력 존중**:
   - 날짜가 명시된 감사/실증 보고서는 당시 측정 시점의 관찰 결과를 보존하는 공식 기록입니다.
   - 현재 구현 상태와 차이가 발생할 경우 과거 기록을 임의 삭제하지 않고 기준일과 변경 사유를 명시합니다.
2. **코드 기반 추적성 (Traceability)**:
   - 모든 기술 사양, 아키텍처 컴포넌트(`CMP-xxx`), API 명세는 실제 소스 코드 경로([`frontend/src/`](../frontend/src/), [`backend/`](../backend/))와 1:1로 일치해야 합니다.
3. **정량 품질 지표 투명성**:
   - 단위 테스트(Vitest, Pytest), 정적 타입 검사(`tsc --noEmit`), 응답 지연 시간(P95 Latency) 등 정량적 수치는 실제 실행 결과를 바탕으로 투명하게 기록합니다.
