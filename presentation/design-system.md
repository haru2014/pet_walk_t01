# 범용 프리젠테이션 디자인 시스템 (Universal Presentation Design System)

이 문서는 프리젠테이션 프로젝트에서 생성하는 모든 PowerPoint(PPTX) 발표 자료의 시각적 일관성과 편집 무결성을 보장하기 위한 디자인 표준입니다.
특정 프로젝트에 국한되지 않고, 비즈니스 보고서, 기술 발표, 교육 및 크리에이티브 발표 등 다양한 목적에 부합하는 다중 테마 및 레이아웃 표준을 정의합니다.

---

## 1. 디자인 기본 원칙 (Core Principles)

1. **내용 중심의 명료성 (Clarity First):**
   - 불필요한 장식이나 복잡한 3D 효과, 그림자를 지양하고 정보의 위계와 전달력을 최우선으로 합니다.
   - 한 슬라이드에는 **하나의 명확한 핵심 메시지(One Slide, One Message)**를 원칙으로 합니다.

2. **완전한 편집 무결성 (Native Editability):**
   - 텍스트를 이미지로 캡처하여 붙여넣지 않고, 순수 PowerPoint 텍스트 상자, 기본 도형, 네이티브 표 및 차트로 구성합니다.
   - 발표자가 생성 후에도 오피스 프로그램(PowerPoint, Keynote 등)에서 폰트, 수치, 색상을 즉각 수정할 수 있어야 합니다.

3. **고대비 및 가독성 (Contrast & Accessibility - 절대 폰트 크기 원칙):**
   - 텍스트와 배경색 간의 충분한 명도 대비를 유지하여 빔프로젝터, 대형 모니터, 화상 회의 화면에서도 쉽게 식별할 수 있도록 합니다.
   - **[절대 원칙] 모든 텍스트(본문, 캡션, 배지, 각주/푸터, 표 셀 포함)의 폰트 사이즈는 12pt 밑으로 절대 내려가지 않습니다 (최소 12pt 이상 보장).**
   - 제목 폰트는 20~32pt, 카드 타이틀은 14~18pt, 본문 및 부가 정보(배지, 캡션, 푸터 등)는 12~14pt를 적용합니다.

4. **표준 그리드와 여백 (Consistent Spacing):**
   - 슬라이드 외곽 여백(Margin)은 좌우 최소 0.8인치, 상하 0.5인치 이상 확보합니다.
   - 카드와 컴포넌트 간 일관된 여백(Gap: 0.2~0.3인치)을 적용하여 정돈된 레이아웃을 제공합니다.

---

## 2. 화면 비율 (Aspect Ratio)

- **16:9 와이드스크린 (`LAYOUT_16x9` - 10" x 5.625" / 권장 기본값):**
  - 현대 모니터, 노트북, 빔프로젝터의 표준 규격입니다.
  - 가로 공간이 넓어 2단·3단 카드, 타임라인, 다중 지표(KPI) 구성에 적합합니다.
- **4:3 표준 화면비 (`LAYOUT_4x3` - 10" x 7.5"):**
  - 구형 빔프로젝터, 출력물 인쇄, 세로형 문서 스타일의 보고서에 적합합니다.

---

## 3. 지원 템플릿 테마 카탈로그 (Themes)

프로젝트 엔진은 목적과 분위기에 맞게 4가지 사전 정의 테마를 지원합니다.

### 1) Modern Business (`modern-business`) - 기본 테마
- **목적:** 경영 실적 보고, 사업 계획서, 전략 제안서, 대외 파트너십 발표
- **스타일:** 신뢰감을 주는 딥 네이비와 로열 블루, 깔끔한 카드 레이아웃
- **색상 팔레트:**
  - 슬라이드 배경: `#F8FAFC` (Slate 50)
  - 카드 배경: `#FFFFFF`
  - 테두리: `#E2E8F0` (경계 1px)
  - 주 강조색(Primary): `#1E40AF` (Deep Blue)
  - 보조 강조색(Accent): `#2563EB` (Royal Blue), `#0D9488` (Teal)
  - 제목 텍스트: `#0F172A` (Slate 900)
  - 본문 텍스트: `#334155` (Slate 700)
- **추천 폰트:** `Pretendard`, `Pretendard`

### 2) Tech Dark (`tech-dark`)
- **목적:** 기술 컨퍼런스, 개발자 밋업, IT 제품 런칭, 스타트업 IR 피치
- **스타일:** 세련된 딥 슬레이트 다크 모드, 네온 시안과 바이올렛 포인트
- **색상 팔레트:**
  - 슬라이드 배경: `#0B0F19` (Deep Charcoal Navy)
  - 카드 배경: `#151E2E`
  - 테두리: `#26354D`
  - 주 강조색(Primary): `#06B6D4` (Cyan)
  - 보조 강조색(Accent): `#38BDF8` (Sky Blue), `#8B5CF6` (Violet)
  - 제목 텍스트: `#F8FAFC` (White Slate)
  - 본문 텍스트: `#CBD5E1` (Light Slate)
- **추천 폰트:** `Pretendard`, `Segoe UI`, `Consolas`

### 3) Warm Pastel / Sorbet (`warm-pastel`)
- **목적:** 라이프스타일, 교육, 부드럽고 친근한 B2C 서비스 소개, 내부 회고
- **스타일:** 파스텔 라일락, 피치 핑크, 민트, 버터 색조와 둥근 모서리(24~32px)
- **색상 팔레트:**
  - 슬라이드 배경: `#FBF7FB`
  - 카드 배경: `#FFFFFF`
  - 테두리: `#ECE3F0` (라일락 틴트)
  - 주 강조색: 라일락 `#9B6FBF`, 피치 `#F2A6B3`, 민트 `#8FD0C4`, 버터 `#F4D58D`
  - 제목 텍스트: `#4A3A5C` (Soft Plum)
  - 본문 텍스트: `#6A5E76`
- **추천 폰트:** `Baloo 2` / `Quicksand` (또는 `Pretendard`)

### 4) Clean Minimal (`clean-minimal`)
- **목적:** 디자인 포트폴리오, 심플 브리핑, 에디토리얼 강연 자료
- **스타일:** 고대비 흑백 모노크롬, 따뜻한 앰버/오렌지 포인트, 여백의 미
- **색상 팔레트:**
  - 슬라이드 배경: `#FAFAFA`
  - 카드 배경: `#FFFFFF`
  - 테두리: `#E5E5E5`
  - 주 강조색: `#171717` (Near Black), 포인트: `#EA580C` (Warm Orange)
  - 제목 텍스트: `#171717`
  - 본문 텍스트: `#404040`
- **추천 폰트:** `Pretendard`, `Arial`

## 4. 슬라이드 레이아웃 카탈로그 (Layouts)

각 슬라이드는 내용의 목적과 구조에 맞춰 아래 11종의 레이아웃 중 최적의 것을 선택하여 적용합니다.

| 레이아웃 식별자 | 명칭 | 주 용도 | 구성 요소 |
|---|---|---|---|
| `cover` | 표지 슬라이드 | 발표의 첫인상 및 메타데이터 전달 | 카테고리 태그, 메인 타이틀, 서브 타이틀, 발표자, 소속, 일자 |
| `agenda` | 목차 슬라이드 | 전체 발표의 3~5개 주요 목차 안내 | 넘버링된 목차 카드, 단계별 요약 설명 |
| `section` | 간지 (섹션 분할) | 큰 주제 전환 및 호흡 조절 | 대형 섹션 번호, 섹션 제목, 핵심 전달 메시지 |
| `key-message` | 핵심 문구 강조 | 청중이 기억해야 할 단 하나의 명제 | 대형 인용문구/명제 박스, 보조 설명 불릿 |
| `columns-2` | 2단 비교 / 대조 | AS-IS vs TO-BE, 문제 vs 해결책, 장단점 | 2개의 비교 카드, 헤더 태그, 상세 항목 불릿 |
| `columns-3` | 3단 병렬 카드 | 3대 핵심 기둥, 주요 기능, 3단계 요약 | 3개의 대등한 카드, 태그 알약, 설명 |
| `cards-4` | 4단 그리드 (2x2) | 4대 영역, SWOT 분석, 주요 실행 과제 | 2x2 균등 카드 그리드, 카드별 제목 및 본문 |
| `timeline` | 타임라인 / 프로세스 | 프로젝트 로드맵, 개발 단계, 연혁 | 수평 프로세스 바, 단계별 노드, 일자/태그, 설명 |
| `metrics` | 핵심 지표 / KPI | 정량적 수치, 성과율, 통계 강조 | 3~4개 대형 수치 카드, 증감율 배지, 설명 |
| `table` | 데이터 테이블 | 사양 비교, 복합 지표 매트릭스 | 헤더 스타일링, 행별 교차 색상, 네이티브 표 |
| `closing` | 마무리 및 Q&A | 감사 인사 및 연락처, 질의응답 유도 | 중앙 집중형 감사 메시지, Q&A 프롬프트, 이메일/링크 |

## 5. 타이포그래피 위계 (Typography Hierarchy)

| 레벨 | 폰트 크기 | 굵기 | 주요 용도 |
|---|---|---|---|
| Display | 32~40 pt | Bold | 표지 메인 제목, 마침 슬라이드 |
| Slide Title | 20~24 pt | Bold | 본문 슬라이드 제목 |
| Section Title | 26~30 pt | Bold | 섹션 간지 메인 제목 |
| Metric Stat | 36~42 pt | Bold | KPI 핵심 지표 숫자 |
| Subtitle | 12~15 pt | Regular / Medium | 슬라이드 상단 보조 설명문 |
| Card Title | 14~16 pt | Bold | 2단/3단 카드 및 목차 항목 제목 |
| Body Text | 10.5~11.5 pt | Regular | 카드 내부 본문, 불릿 설명 |
| Caption / Tag | 9~10 pt | Bold / Regular | 카테고리 배지, 출처, 슬라이드 번호 |

## 6. 품질 검토 및 무결성 체크리스트

발표 자료를 최종 배포하기 전 다음 사항을 반드시 확인합니다:
- [ ] **텍스트 오버플로우:** 카드나 박스를 벗어나는 텍스트 잘림이 없는가?
- [ ] **단위 및 레이블:** 모든 수치(Metrics)에 단위(%, 원, 개사 등)와 기준 시점이 명시되어 있는가?
- [ ] **대비 및 가독성:** 배경색과 글자색의 대비가 명확하여 가독성이 충분한가?
- [ ] **편집 가능성:** 텍스트나 표가 비트맵 이미지가 아닌 네이티브 객체인가?
- [ ] **발표자 노트:** 복잡한 배경 설명이나 상세 근거가 발표자 노트에 충실히 기재되었는가?

## 부록: 편안하개 발표 테마 (`templates/petwalk.json`)

편안하개 발표는 위 범용 기준을 따르되, 앱과 같은 인상을 주도록 앱 디자인 토큰(`frontend/src/theme/tokens.ts`)의 색을 씁니다. 이전 초안의 Sorbet 라일락 팔레트는 앱 화면 캡처와 색이 어긋나 교체했습니다(이전 내용은 git 이력에 남아 있습니다).

- 비율 4:3, 폰트 Pretendard (없으면 맑은 고딕으로 대체), 최소 글자 크기 12pt
- 슬라이드마다 핵심 메시지 하나, 출처는 하단 `[출처]`, 발표 설명은 발표자 노트

| 역할 | HEX |
|---|---|
| 배경 | #F5EFE0 (크림) |
| 카드 면 | #FDFAF4 |
| 주색·강조 | #5A7361 (포레스트 그린), 연한 면 #E3ECE4 |
| 보조색 | #CFA052 (머스터드), 연한 면 #F7ECCF, 강조 글자 #8A5A12 |
| 3차색 | #49657A (스틸 블루) |
| 제목 / 본문 / 보조 글자 | #2D3A31 / #3E5244 / #566659 |

앱 화면 캡처는 `content-image` 레이아웃으로 오른쪽 카드에 넣고, 캡션에 캡처 날짜를 적습니다.
